## 사전 준비

- `git submodule update --init --recursive`로 컴포넌트 버전을 맞춘다.
- `.env.example`을 기준으로 필요한 환경변수를 준비한다.
- 실제 비밀값은 저장소에 커밋하지 않는다.
- `docs/TEST_STRATEGY.md`의 배포 진입 조건을 확인한다.

## 배포 확인
