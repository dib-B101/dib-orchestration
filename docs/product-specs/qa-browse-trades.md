# 탐색·거래 화면 QA 인수 조건

> 상태: Active

## 탐색

- 홈·피드·내 거래·마이에서 화면을 아래로 당기면 각 화면의 서버 데이터를 새로 조회한다.
- 홈 경매 카드에는 입찰 횟수를 표시하지 않고 남은 시간을 일·시·분을 포함해 읽기 쉽게 표시한다.
- 홈 ‘라이브 모두 보기’는 라이브 전용 목록을 열며 그리드와 리스트를 전환할 수 있다.
- 카테고리에서 상품 상세를 보고 돌아오면 이전 상품 목록과 스크롤 위치가 유지된다.
- 카테고리 화면에는 검색박스를 표시하지 않는다. 상품 검색은 별도 검색 화면에서 제공한다.
- 카테고리와 찜한 경매 카드의 상품 이미지는 카드 너비에 맞춰 일정한 비율을 유지한다.

## 거래와 상품 상세

- 구매 탭에 표시되는 경매는 입찰 탭에 중복 표시하지 않는다.
- 비슷한 상품에는 진행 중인 경매를 표시하며 선택 시 일반 경매 상세로 진입해 입찰할 수 있다.
- 상품 상세의 배송 정보·상품 설명·상품 정보는 입찰 이력 위에 같은 카드 형식으로 표시한다.
- 정상 실시간 연결 상태 문구는 표시하지 않고 연결 오류는 안내한다.
- 입찰 금액은 직접 입력하거나 1,000원·5,000원·10,000원 단위로 증액하며 ±10원 버튼은 제공하지 않는다.

## 상품 등록·수정

- 구매 연도는 모든 카테고리에서 선택 입력이며, 모르면 비워둘 수 있다.
- 상품 등록·수정 입력란은 필수 항목에만 `*`를 표시한다. 선택 항목의 라벨에는 `(선택)`을 붙이지 않으며 카테고리별 입력란의 예시 텍스트는 공통 입력란과 같은 스타일로 표시한다.
- 추가 정보의 명칭과 항목은 선택한 카테고리에 맞게 표시하고 상품 상세에도 같은 명칭으로 보여준다.
- 티켓·교환권·e쿠폰은 유효기간과 미사용 여부, 가공식품·건강기능식품은 소비기한과 미개봉 여부를 등록 시 확인한다.
- 모델명·출시연도 등 기존 상품의 정보도 상세 화면에서 읽을 수 있다.

## 공통 UI

- 마이페이지의 바로가기와 정보·설정 메뉴는 한 카드의 그리드로 제공하며, 경매·구매, 정산·문의, 알림·계정 관련 항목 순서로 배치하고 각 항목의 이동 기능을 유지한다.
- 등록 상품 관리에서 상품 삭제는 카드 상단의 보조 동작으로 표시한다. 경매 시작·수정 동작이 없을 때 빈 하단 동작 영역을 만들지 않는다.
- 배송지 수정의 입력 순서는 새 배송지 추가와 동일하게 우편번호 검색, 주소, 상세주소, 배송지 이름이다. 저장된 상세주소는 수정 화면을 다시 열 때 입력란에 채워진다.
- 배송지와 정산 계좌 입력란의 테두리가 밝은 배경에서도 구분된다.
- 신고 상세의 처리 상태 안내는 한 곳에서 현재 상태에 맞는 문구로 표시한다.
- 피드의 하단 내비게이션은 다른 기본 탭과 동일한 안전 영역에 배치한다.
- Live 피드를 넘길 때 시청자 수는 해당 방송에서 받은 실시간 값만 숫자로 표시하고, 이전 방송의 댓글 응답이나 소켓 메시지를 새 방송에 보여주지 않는다.
