# 탐색·거래 화면 QA 인수 조건

> Status: Active

## 탐색

- 홈·피드·내 거래·마이에서 화면을 아래로 당기면 각 화면의 서버 데이터를 새로 조회한다.
- 홈 경매 카드에는 입찰 횟수를 표시하지 않고 남은 시간을 일·시·분을 포함해 읽기 쉽게 표시한다.
- 홈 ‘라이브 모두 보기’는 라이브 전용 목록을 열며 그리드와 리스트를 전환할 수 있다.
- 카테고리에서 상품 상세를 보고 돌아오면 이전 상품 목록과 스크롤 위치가 유지된다.
- 카테고리와 찜한 경매 카드의 상품 이미지는 카드 너비에 맞춰 일정한 비율을 유지한다.

## 거래와 상품 상세

- 구매 탭에 표시되는 경매는 입찰 탭에 중복 표시하지 않는다.
- 비슷한 상품에는 진행 중인 경매를 표시하며 선택 시 일반 경매 상세로 진입해 입찰할 수 있다.
- 상품 상세의 배송 정보·상품 설명·상품 정보는 입찰 이력 위에 같은 카드 형식으로 표시한다.
- 정상 실시간 연결 상태 문구는 표시하지 않고 연결 오류는 안내한다.
- 입찰 금액은 직접 입력하거나 1,000원·5,000원·10,000원 단위로 증액하며 ±10원 버튼은 제공하지 않는다.

## 공통 UI

- 배송지와 정산 계좌 입력란의 테두리가 밝은 배경에서도 구분된다.
- 신고 상세의 처리 상태 안내는 한 곳에서 현재 상태에 맞는 문구로 표시한다.
- 피드의 하단 내비게이션은 다른 기본 탭과 동일한 안전 영역에 배치한다.
