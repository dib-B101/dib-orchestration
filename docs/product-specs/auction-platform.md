# Auction Platform Product Specification

상태: Draft
기준 원본: [B101 명세서 Google Sheet](https://docs.google.com/spreadsheets/d/1qjqjh2OFjFtgLKkJVJVqcNBo5vOF85LSEs8z4MNtQAg/edit)

## 목적

DIB는 하나의 상품·경매 코어 위에서 쇼핑몰형 일반 경매와 세로형 실시간 Live 경매를 제공한다. 두 유형은 탐색과 시작 방식이 다르지만 입찰, 보증금, 연장, 낙찰, 거래 정책은 공유한다.

## 핵심 개념

| 개념 | 의미 |
| --- | --- |
| Product | 판매자가 등록하고 AI 검수를 받는 판매 대상. 경매와 분리해 관리한다. |
| Auction | 입찰·가격·종료·낙찰의 공통 단위. `GENERAL` 또는 `LIVE` 유형을 가진다. |
| General Auction | 미래 시작시각에 자동 시작되는 쇼핑몰형 단일 상품 경매다. |
| Live Broadcast | 판매자의 실시간 세로형 방송이다. 최대 10개 상품을 순서와 함께 편성한다. |
| Live Item | Live에 편성된 상품과 상품별 시작가·인상액·진행시간 설정이다. |
| Bid Deposit | 경매별 최초 입찰 전에 한 번 결제하는 입찰 보증금이다. |
| Order | 경매 종료 후 낙찰자와 판매자 사이에 생성되는 거래 단위다. |

## 경매 유형 비교

| 구분 | 일반 경매 | Live 경매 |
| --- | --- | --- |
| 탐색 | 쇼핑몰형 홈·목록·검색·상세 | 방송 중 Live만 제공하는 세로형 피드 |
| 주요 섹션 | 추천, 마감 임박, 인기, 전체 목록 | 개인화 또는 인기 기반 Live 피드 |
| 시작 | 판매자가 예약하고 시스템이 자동 시작 | 방송 중 판매자가 편성 상품을 수동 시작 |
| 종료 | 최종 종료시각에 자동 종료 | 상품별 제한시간에 자동 종료 |
| 상품 관계 | 경매 1개당 상품 1개 | Live 1개당 편성 상품 최대 10개, 동시 경매 1개 |
| 다음 경매 | 해당 없음 | 이전 상품 종료 후 판매자가 다음 상품을 수동 시작 |
| 익명 조회 | 목록·검색·상세·마스킹 입찰 이력 | 영상, 현재 상품·경매 상태와 시청자 수만 |

## 핵심 사용자 흐름

### 일반 경매

1. 판매자가 상품을 등록하고 AI 검수 통과를 기다린다.
2. 승인된 상품을 선택해 시작가, 최소 인상 금액, 시작일시와 종료일시를 설정한다.
3. 경매는 `SCHEDULED`로 생성되며 판매자는 시작 전 수정하거나 취소할 수 있다.
4. 시스템이 시작시각에 상품의 판매 가능성과 중복 노출 여부를 재검증하고 `ACTIVE`로 전환한다.
5. 비회원과 회원은 쇼핑몰형 홈·목록·검색·상세에서 경매를 조회한다.
6. 로그인 회원은 보증금을 결제하고 입찰한다.
7. 최종 종료시각에 낙찰 또는 유찰로 종료하고 후속 거래·환불을 진행한다.

### Live 경매

1. 판매자가 방송 제목·대표 이미지를 설정하고 승인 상품을 최대 10개까지 편성한다.
2. 편성 상품마다 시작가, 최소 인상 금액과 진행시간을 설정한다.
3. 송출 상태가 `ONLINE`이면 판매자가 Live를 시작한다. 첫 상품 경매는 자동 시작하지 않는다.
4. 비회원과 회원은 방송 중인 Live만 세로형 피드로 탐색한다.
5. 판매자가 한 상품의 경매를 시작하며 같은 Live에는 `ACTIVE` 경매가 하나만 존재한다.
6. 상품 경매가 자동 종료되어도 다음 상품은 자동 시작하지 않는다.
7. 진행 중 상품 경매가 없을 때만 판매자가 Live를 종료할 수 있다.

## 공통 경매 정책

- 최초 입찰 보증금은 최초 입찰 금액의 10%이며 최소 1,000원이다.
- 추가 입찰 시 보증금을 증액하지 않는다.
- 새 입찰가는 현재 최고가와 최소 인상 금액의 합 이상이어야 하며 입찰 상한과 즉시구매는 제공하지 않는다.
- 최소 인상 금액은 1,000원 이상이다.
- 마감 30초 이내 유효 입찰이 발생하면 종료시각을 15초씩 횟수 제한 없이 연장한다.
- 판매자는 자신의 상품 경매에 입찰할 수 없고 현재 최고 입찰자는 자기 입찰가를 다시 올릴 수 없다.
- 입찰이 없거나 낙찰자가 24시간 안에 결제하지 않으면 차순위 승계 없이 유찰 처리한다.
- 패찰·유찰·관리자 판매중지 시 보증금을 전액 환불한다. 일반적인 낙찰 후 결제 포기는 보증금 몰수와 경고 대상이다.

## 상품 점유와 재사용

- 한 상품은 `SCHEDULED` 또는 `ACTIVE` 일반 경매와 진행 중 Live 편성에 동시에 존재할 수 없다.
- 예약 일반 경매 상품을 Live에 편성하려면 일반 경매를 먼저 취소해야 한다.
- 미판매·유찰 상품은 종료 이력을 유지한 채 일반 경매 또는 다른 Live에 다시 등록할 수 있다.
- 판매 완료 상품은 다시 경매할 수 없다.

## Live 송출 장애

- 송출이 `DEGRADED`이면 진행 중 경매 상품의 대표 이미지로 화면을 대체한다. 경매가 없으면 Live 대표 이미지를 사용한다.
- 이미 진행 중인 경매의 타이머와 입찰 처리는 계속한다.
- 장애 상태에서는 새 상품 경매를 시작할 수 없다.
- 경매 종료 또는 무경매 시점부터 5분 복구 타이머를 시작한다.
- 5분 안에 복구되지 않으면 Live를 자동 종료한다.

## 인수 조건

- 일반 경매와 Live 경매가 공통 `auctionId` 기반 입찰 계약을 사용한다.
- 일반 경매는 예약 시작 전만 수정·취소할 수 있고 예약시각에 자동 시작한다.
- 익명 사용자가 일반 경매 공개 정보와 마스킹 이력을 조회할 수 있으나 입찰 등 상태 변경은 할 수 없다.
- 익명 Live 사용자는 영상·현재 상품·경매 상태·시청자 수 외의 회원 기능에 접근할 수 없다.
- 익명 Live 행동은 `IMPRESSION`, `VIEW_START`, `DWELL`, `SKIP`만 기록한다.
- 동일 상품의 일반·Live 중복 노출이 생성 시점과 시작 시점 모두에서 차단된다.
- Live에서 동시에 두 상품 경매를 시작하거나 진행 중 경매가 있는 상태로 방송을 종료할 수 없다.
- 송출 장애에서도 현재 경매가 계속되고 복구 제한시간 정책이 적용된다.

## 미결정 사항

- 일반 경매 추천·인기 점수의 입력 신호, 가중치, 개인화 여부와 갱신 주기
- 스트리밍 공급자와 공급자별 송출·재생 계약
- 최종 물리 ERD, DB 타입과 인덱스
- 제품 성공 지표와 목표값
