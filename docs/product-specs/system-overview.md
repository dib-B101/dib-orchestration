# System Overview

상태: Draft

## 문제 정의

DIB는 일반 경매와 Live 방송 경매를 한 거래 흐름 안에서 제공하는 중고 거래 서비스다.

## 제품 목표

- 상품 탐색부터 입찰, 낙찰, 결제, 배송과 정산까지 연결된 거래 경험을 제공한다.
- 일반 경매와 Live 경매를 지원한다.
- 상품 검수, 이상 입찰 탐지와 추천에 AI를 활용한다.
- 실시간 상호작용과 안정적인 거래 처리를 지원한다.

## 대상 사용자

| 사용자 | 역할 |
| --- | --- |
| 비회원 | 공개된 상품, 경매와 Live를 탐색한다. |
| 회원 | 구매자 또는 판매자로 상품, 경매와 거래 기능을 사용한다. |
| 관리자 | 회원, 상품, 문의, 신고와 거래 운영 업무를 처리한다. |

## 시스템 범위

### 포함

- 회원과 인증
- 상품 등록·탐색과 검수
- 일반·Live 경매와 실시간 입찰
- 주문, 결제, 배송, 거래 확정과 정산
- 채팅, 알림, 문의와 신고
- AI 기반 검수, 탐지와 추천

### 상세 명세 관리

요구사항, 기능, API와 ERD는 개발 중 변경되는 작업 자료이므로 이 저장소에 복제하지 않는다. 관련 작업을 수행할 때 사용자가 제공한 최신 Sheet와 ERD를 해당 작업의 기준으로 사용한다.

확정된 시스템 수준 결정만 `ARCHITECTURE.md`와 관련 실행 계획에 기록하고, 컴포넌트 내부 구현과 실행 가능한 스키마는 해당 submodule이 소유한다.
