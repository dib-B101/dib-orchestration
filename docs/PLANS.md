# Planning Guide

작고 국소적인 변경은 작업 중 체크리스트로 관리할 수 있다. 여러 컴포넌트에 영향을 주거나 장시간 진행되는 작업은 `exec-plans/active/`에 버전 관리되는 실행 계획을 작성한다.

실행 계획은 작업 중 계속 갱신하며 다음을 포함해야 한다.

- 명확한 범위와 완료 조건
- 영향받는 컴포넌트
- 현재 진행 상황
- 주요 결정과 이유
- 실행한 검증과 결과
- 미해결 문제와 후속 작업

완료된 계획은 결과와 남은 후속 작업을 기록한 뒤 `exec-plans/completed/`로 이동한다.
