# QA 화면 및 거래 흐름 수정

> Status: Active

## 범위

- Android 앱의 홈·피드·내 거래·마이 새로고침과 공통 입력·알림·신고 UI 개선
- 내 거래의 구매 완료 경매 중복 제거
- 홈 카드 정보, 라이브 목록, 상품 상세 정보 구성과 비슷한 상품 입찰 경로 수정
- 카테고리 복귀 시 목록·스크롤 위치 유지 및 카드 비율, 피드 하단 내비 위치, 찜 카드 비율 수정
- 입찰 금액 ±10원 버튼 제거

## 완료 조건

- 선택한 네 화면에서 아래로 당겨 새로고침할 수 있다.
- 구매 탭에 존재하는 경매는 입찰 탭에 중복 표시되지 않는다.
- 홈 ‘라이브 모두 보기’에서 라이브 목록의 그리드·리스트 보기를 전환할 수 있다.
- 비슷한 상품 중 진행 중인 경매는 동일한 경매 상세 화면으로 열리고 입찰할 수 있다.
- 카테고리 상품 상세에서 돌아오면 이전 상품 목록과 스크롤 위치가 유지된다.
- 변경 화면의 카드 비율과 텍스트 입력 테두리가 화면 크기에 관계없이 보인다.

## 결정 기록

- 새로고침 범위: 홈·피드·내 거래·마이.
- 구매 완료 상품: 입찰 탭에서 제외.
- ±10원 버튼 제거. 기존 직접 입력과 큰 금액 증감 버튼은 유지.
- 비슷한 상품: 진행 중인 경매만 노출하고 일반 경매 상세로 이동.
- 라이브 모두 보기: 별도 목록 화면.
- 연결 정상 상태 문구 제거, 오류 상태는 유지.
- 배송 정보·상품 설명·상품 정보를 동일한 카드 스타일로 입찰 이력 위에 배치.
- 신고 처리 안내는 한 곳에만 표시.
- 홈 경매 카드에서 입찰 횟수를 제거하고 남은 시간을 일·시·분 단위로 표시.
- 카테고리 복귀 시 기존 목록과 스크롤 위치 유지.

## 검증 결과

- 프론트엔드와 orchestration에서 `git diff --check` 통과.
- `:app:compileDebugKotlin --offline`은 Android SDK가 설치되지 않아 소스 컴파일 전 `SDK location not found`로 중단.
- 카테고리 상태는 화면의 back stack entry에 속한 ViewModel에 보관해 상품 상세에서 돌아온 뒤 재조회로 목록이 바뀌지 않도록 구성.
- orchestration의 컴포넌트 포인터는 프론트엔드 PR 병합 전까지 갱신하지 않는다.
- 프론트엔드 `87d7f32`를 `hotfix/qa-ui-trades`에 푸시하고 [draft PR #227](https://github.com/dib-B101/dib-frontend/pull/227)을 생성했다.
