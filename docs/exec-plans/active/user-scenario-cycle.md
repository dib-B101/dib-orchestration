# Execution Plan: 사용자 거래·라이브 전체 사이클 검증

상태: In progress
소유자: DIB team
시작일: 2026-09-18

## 목적

회원가입부터 상품, 검수, 경매, 입찰, 낙찰, 결제, 배송, 구매확정, 정산까지 실제 사용자 흐름을 검증한다. 라이브 경매, 재연결, 신고, 문의 흐름도 포함한다.

## 범위

### 포함

- 일반 회원가입과 로그인
- 상품 등록, AI 검수 승인·거절·재검수
- 일반·라이브 경매 생성, 시작, 동시입찰, 종료, 유찰, 재등록
- 결제 실패·기한 만료·후순위 제안·정상 결제
- 배송, 구매확정, 자동 구매확정, 정산
- 상품·주문·라이브 신고의 접수 및 백엔드 관리자 처리
- 문의 등록, 관리자 답변, 알림, 추가 문의
- 방송 재연결 뒤 경매 상태 복구

### 제외

- 소셜 로그인: 외부 OAuth 준비 전 제외
- 프론트 관리자 화면: 미구현이므로 관리자 API를 직접 검증
- 실 결제·실 배송사 호출: 로컬 fake 또는 명시적 실패 응답으로 검증

## 완료 조건

- Backend, Frontend, AI 전체 테스트와 빌드가 통과한다.
- 같은 가격 동시입찰은 정확히 1건만 성공한다.
- 서로 다른 가격 동시입찰 뒤 최고가·최고입찰자가 일치한다.
- 경매 종료 뒤 무입찰은 유찰, 입찰 존재 시 주문이 생성된다.
- 결제 기한 만료 뒤 후순위 제안·수락·결제가 정상 전이된다.
- 배송·구매확정·자동확정 뒤 거래와 정산 상태가 일치한다.
- 신고 중 거래·정산 보류 및 처리 결과가 일치한다.
- 라이브 두 클라이언트에 가격·상태가 실시간 전파되고 재접속 Snapshot이 복구된다.
- 제외 항목 외 각 흐름에 반복 실행 가능한 테스트 또는 명시적 실행 절차가 있다.
