# QA 회원가입·마감임박 수정

## 범위와 완료 조건

- Android 회원가입 생년월일 입력 중 커서가 예기치 않게 이동하지 않는다.
- 이메일 회원가입 직후 저장된 인증 세션으로 보호 기능을 사용할 수 있다.
- 홈 마감임박 경매의 시간이 끝나면 종료를 표시하고 입찰 동작을 제공하지 않는다.
- 종료된 경매를 다시 확인할 때 진행 상태와 남은 시간이 되살아나지 않는다.

## 영향 컴포넌트

- Frontend: 가입 폼, 인증 전환, 홈 경매 상태 표시.
- Backend: 종료 상태 전환과 추천 응답을 조사한 뒤 필요할 때만 수정.

## 진행 상황

- [x] QA 재현 화면 확인: 이메일 가입 직후, 홈 마감임박.
- [x] 최신 `main` 기준 원격 코드 조사.
- [x] Android 화면 및 상태 전환 경로 수정, 회귀 테스트 추가.
- [ ] 실기기에서 회원가입과 경매 종료 흐름 확인.
- [ ] submodule 포인터와 검증 결과 기록.

## 결정 기록

- 2026-09-22: `main`에서 `hotfix/qa-signup-auction` 브랜치를 만들어 QA 수정 작업을 진행한다.
- 2026-09-22: 회원가입 응답의 토큰은 Android 저장소에서 이미 저장한다. 가입 직후 로그인 상태 전환과 이후 요청의 영향을 확인한다.
- 2026-09-22: 백엔드 추천은 DB에서 `ACTIVE` 상태를 확인하지만, 홈의 마감임박 카드는 0초 뒤에도 입찰 버튼을 유지한다.
- 2026-09-22: 홈은 이전 추천 목록을 재진입 때 다시 읽지 않았고, 상세 화면은 서버 스냅샷의 `status`를 버렸다. 앱에서 재조회와 종료 상태 반영을 수정한다.
- 2026-09-22: 가입 직후 보호 탭 접근 시 저장된 세션을 복구하고, 가입 토큰이 거절되면 자동 로그인으로 재발급한다.
- 2026-09-22: Frontend 커밋 `377eb45`를 draft PR [#226](https://github.com/dib-B101/dib-frontend/pull/226)로 제출했다. 병합 전에는 orchestration의 submodule 포인터를 갱신하지 않는다.

## 검증 결과

- `git diff --check`: 통과.
- `./gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --no-daemon`: Android SDK가 없어 작업 그래프 구성 단계에서 실패했다. 코드 컴파일과 테스트는 실행되지 않았다.

## 미해결 문제

- Android SDK가 있는 환경에서 빌드·테스트와 실기기 QA를 실행해야 한다.
- 실환경에서 종료 후에도 서버가 `ACTIVE`를 반환한다면 해당 경매의 서버 로그와 DB 상태를 확인해야 한다.
