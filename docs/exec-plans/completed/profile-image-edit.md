# 프로필 이미지 수정

## 범위와 완료 조건

- Android 프로필 수정에서 갤러리 이미지를 선택하고 미리보기, 저장할 수 있다.
- 서버가 인증된 회원의 이미지를 저장하고 이후 내 정보 조회에 새 이미지 URL을 반환한다.
- 긴 프로필 텍스트가 입력칸 밖으로 잘리지 않는다.
- 관련 프론트엔드 빌드와 백엔드 테스트가 통과한다.

## 영향받는 컴포넌트

- `components/frontend`: 프로필 화면, 이미지 선택·업로드, 회원 모델
- `components/backend`: 프로필 이미지 업로드 API

## 결정

- 사진은 시스템 갤러리에서 선택한다.
- 서버는 기존 이미지 저장소의 파일 검증과 저장 기능을 재사용한다.
- 프로필 수정 API는 기존 닉네임 수정과 별도로 사진 업로드를 받는다.

## 검증 결과

- 프론트엔드 `:app:testDebugUnitTest --offline` 통과
- 백엔드 `MemberProfileImageServiceTest`, `MemberCommandControllerTest` 통과
- 프로필 이미지 MIME·크기 검증, 저장 실패 시 새 이미지 정리, 기존 이미지 교체 테스트 통과
