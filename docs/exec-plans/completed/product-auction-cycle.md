# 상품 등록-경매 시작 사이클 정리

## 범위와 완료 조건

- 상품 등록 시 시작가와 경매 시간을 한 번만 입력한다.
- AI 검수 미연동 기간에는 신규/수정 상품을 즉시 승인 처리한다.
- 등록과 동시에 같은 조건의 예정 경매 하나를 만든다.
- 승인 상품 화면에서 저장된 조건을 확인하고 바로 경매를 시작한다.
- 중복 경매 생성과 조건 재입력 경로를 제거한다.

## 영향 컴포넌트

- Backend: 상품/경매 상태 전이, 내 상품 조회 SQL, 테스트
- Frontend: 내 상품 모델, 경매 시작 화면/내비게이션, 문구, 테스트

## 결정

- 현재 AI 검수는 항상 통과로 간주해 `ProductStatus.REGISTERED`를 즉시 저장한다.
- 경매는 상품 등록 트랜잭션에서 `AuctionStatus.SCHEDULED`로 한 번만 생성한다.
- 경매 시작은 기존 `PATCH /api/v1/auctions/{auctionId}/start`를 사용한다.
- 시작 전 조건 수정은 이번 사용자 흐름에서 제거한다. 조건 변경은 상품 수정 흐름에서만 다룬다.
