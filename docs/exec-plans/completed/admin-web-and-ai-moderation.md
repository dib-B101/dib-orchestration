# Execution Plan: 관리자 웹과 상품 AI 검수 활성화

상태: Complete
소유자: Codex
시작일: 2026-09-21

## 목적

로컬 통합 환경에서 상품 등록 AI 검수를 활성화하고, 운영자가 문의·AI 검수·이상 입찰·신고·회원 상태를 실제 백엔드 API로 관리할 수 있는 웹 프런트엔드를 제공한다.

## 범위

### 포함

- Docker Compose 로컬 환경의 상품 AI 검수 활성화
- 관리자 이메일/비밀번호 로그인과 토큰 갱신·로그아웃
- 문의 목록·상세·답변 처리
- 상품 AI 검수 대기/결과 확인과 승인·반려 처리
- 이상 입찰 탐지 목록 확인
- 신고 목록·상세·처리 및 대상 회원 정지/해제
- 로컬 개발 실행 문서와 통합 구성 갱신

### 제외

- 운영 환경 배포
- 새로운 AI 모델 학습 또는 추론 로직 변경
- 기존 Android 앱 UI 변경

## 완료 조건

- 관리자 웹이 프로덕션 빌드에 성공한다.
- 로컬 백엔드 API와 인증된 관리자 흐름이 연결된다.
- AI 검수 플래그가 활성화되고 상품 등록 검수 계약이 실제 구현돼 있음을 검증한다.
- 문의, 검수, 이상 입찰, 신고, 회원 정지/해제 화면이 오류·로딩·빈 상태를 처리한다.
- 관련 아키텍처 및 실행 문서가 갱신된다.

## 영향받는 컴포넌트

- `components/frontend`: 관리자 웹 애플리케이션
- `components/backend`: 기존 관리자 API 계약 확인 및 필요한 최소 보완
- `components/ai`: 기존 상품 검수 계약 확인
- 루트 orchestration: Compose 플래그, 문서, 컴포넌트 관계
